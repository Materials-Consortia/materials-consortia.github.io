# How to cite

If OPTIMADE has been useful to you, please cite it. Citations are how the
consortium shows that the work is worth continuing.

## The OPTIMADE API

- Evans *et al*, Developments and applications of the OPTIMADE API for materials discovery, design, and data exchange, *Digital Discovery* (2024) [10.1039/D4DD00039K](https://doi.org/10.1039/D4DD00039K){:target="_blank"} (preprint: [10.48550/arXiv.2402.00572](https://doi.org/10.48550/arXiv.2402.00572){:target="_blank"})
- Andersen *et al*, OPTIMADE, an API for exchanging materials data, *Sci. Data* **8**, 217 (2021) [10.1038/s41597-021-00974-z](https://doi.org/10.1038/s41597-021-00974-z){:target="_blank"}

## The specification document

- Andersen *et al*, The OPTIMADE Specification, *Zenodo*, [10.5281/zenodo.4195050](https://doi.org/10.5281/zenodo.4195050){:target="_blank"}

## The Python implementation

If you used `optimade-python-tools` to serve or consume an OPTIMADE API, please
also cite:

- Evans *et al*, `optimade-python-tools`: A Python library for serving and consuming materials data via OPTIMADE APIs, *Journal of Open Source Software* **6** (65), 3458 (2021) [10.21105/joss.03458](https://doi.org/10.21105/joss.03458){:target="_blank"}

## Also cite the database

OPTIMADE gives you access to other people's data. Each database has its own
citation requirements, and querying it through a common API does not replace
them. Check the provider's own terms, which you can reach from the
[providers dashboard](https://www.optimade.org/providers-dashboard/){:target="_blank"}.
